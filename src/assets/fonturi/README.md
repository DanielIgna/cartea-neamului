# Fonturi pentru cardurile /api/card

`alegreya-ro-500.woff` și `alegreya-ro-700.woff` sunt Alegreya (The Alegreya Project Authors, licența SIL Open Font
License 1.1), luate din `@fontsource/alegreya` (subseturile latin și latin-ext) și lipite într-un singur fișier pe grosime,
ca literele românești (ș, ț, ă, î, â) să se deseneze la fel ca restul în cardurile de previzualizare.
Refacere: fontTools `Merger` pe cele două fișiere .woff, salvat ca woff.
